=== 中文详细说明 ===

TinyPalette 是一款轻量可爱的浏览器色彩小助手，专为设计师、前端开发者和需要随手查看色值的人打造。输入 HEX 即可即时预览，并自动转换为 RGB 与 HSL；也可以打开内置的 HSL 可视化取色面板自由拖拽选色，或使用页面吸色器直接从当前网页吸取颜色。

支持一键复制 HEX、RGB、HSL 与现成 CSS 代码片段，配色工作更简单。界面支持英文与简体中文一键切换，你还可以自定义主题强调色，让整个弹窗自动染上你喜欢的色调。所有偏好仅保存在本地，无需联网权限，也不收集任何用户数据。

主要功能：
• 输入 HEX 即时预览，自动转换 RGB / HSL
• 内置色相 / 饱和度 / 明度取色面板
• 页面吸色器，从任意网页直接取色
• 一键复制 HEX、RGB、HSL、CSS
• 自定义主题强调色，界面色调同步跟随
• 中英双语界面
• 纯本地运行，无数据收集


=== English Detailed Description ===

TinyPalette is a lightweight, delightful color companion for designers, front-end developers, and anyone who checks color values on the fly. Enter a HEX code to instantly preview it and get automatic RGB/HSL conversions. Open the built-in HSL color picker to drag and select any shade, or use the page eyedropper to grab a color straight from the webpage you're viewing.

Copy HEX, RGB, HSL, or a ready-to-use CSS snippet with one click. The popup supports English and Simplified Chinese, and you can customize the accent theme color so the whole interface tints to match. All preferences stay local; no network permissions are needed, and no data leaves your device.

Key features:
• Instant HEX preview with RGB/HSL conversion
• Built-in hue/saturation/lightness color picker
• Page eyedropper for picking colors from any site
• One-click copy for HEX, RGB, HSL, and CSS
• Custom accent theme color with matching UI tint
• Bilingual UI: English and Simplified Chinese
• Purely local, no data collection
