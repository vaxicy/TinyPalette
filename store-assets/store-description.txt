=== 中文详细说明 ===

TinyPalette 是一款轻量可爱的浏览器色彩小助手，专为设计师、前端开发者和任何需要随手查看色值的人打造。输入 HEX 色值即可即时预览，并自动转换为 RGB 与 HSL；也可以打开内置的可视化取色面板，自由拖拽选择理想颜色。

支持一键复制 HEX、RGB、HSL 或现成的 CSS 片段，配色工作变得简单高效。界面支持英文与简体中文一键切换，你还可以自定义主题强调色，让整个弹窗的色调跟随你的选择自动变化。所有语言与主题偏好仅保存在本地，无需联网权限，安装后点击 Chrome 工具栏图标即可随时使用。

TinyPalette 纯本地运行，不收集、不上传任何用户数据，所有颜色计算都在浏览器内完成。

主要功能：
• 输入 HEX 即时预览，自动转换 RGB / HSL
• 一键复制 HEX、RGB、HSL 与 CSS 代码片段
• 内置色相 / 饱和度 / 明度取色面板，拖拽自由选色
• 主题强调色自定义，界面色调同步跟随
• 中英双语界面，本地存储偏好
• 轻量无干扰，开箱即用


=== English Detailed Description ===

TinyPalette is a lightweight, delightful color companion for designers, front-end developers, and anyone who needs to check color values on the fly. Enter a HEX code to instantly preview it, with automatic conversion to RGB and HSL. You can also open the built-in visual color picker to drag and select any color you like.

Copy HEX, RGB, HSL, or a ready-to-use CSS snippet with one click, making color workflows fast and simple. The interface supports English and Simplified Chinese switching, and you can customize the accent theme color so the entire popup automatically tints itself to match. All language and theme preferences are stored locally; no network permissions are required. Just click the TinyPalette icon in the Chrome toolbar whenever you need a color.

TinyPalette runs entirely on your device. It does not collect or upload any user data, and all color calculations happen inside the browser.

Key features:
• Enter a HEX value for instant preview and RGB / HSL conversion
• One-click copy for HEX, RGB, HSL, and CSS snippet
• Built-in hue / saturation / lightness color picker with drag-to-select
• Customizable accent theme color with matching UI tint
• Bilingual UI: English and Simplified Chinese
• Lightweight and distraction-free, ready to use out of the box
